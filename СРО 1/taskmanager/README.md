Индивидуальный проект самостоятельной работы обучающихся (СРО №1) по дисциплине **«Визуальное программирование»**.

* **Образовательная программа:** 6B06101 — Информационные системы
* **Курс:** 3 | **Семестр:** 5
* **Преподаватель:** Сеньор-лектор Рашидинов Д.Р.
* **Технологии:** Java 21, JavaFX 19, FXML, Maven, IntelliJ IDEA, [image_Ehl16c.png]

---

## 🎯 Цель проекта
Закрепление практических навыков проектирования графического пользовательского интерфейса (GUI), обработки событий компонентов, динамической фильтрации коллекций и разделения архитектурной логики приложения на представление (FXML) и контроллеры (Java),.

---

## 🚀 Технические особенности и компоненты

Приложение полностью удовлетворяет обязательным техническим требованиям методического указания:
1. **Разделение логики:** Разметка интерфейса полностью вынесена в декларативный файл `hello-view.fxml`, а обработка действий пользователя изолирована в классе `HelloController.java`.
2. **Контейнеры компоновки:** Использованы менеджеры компоновки `BorderPane`, `VBox` и `HBox` для построения адаптивного интерфейса.
3. **Элементы управления (Controls):** Внедрены 5 различных типов элементов: `TableView`, `Button`, `TextField`, `ComboBox`, `Label`.
4. **Отображение коллекций:** Свойства задачи (`Task`) используют архитектуру `StringProperty`, что обеспечивает реактивное автоматическое обновление строк таблицы `TableView` при изменении данных.
5. **Динамический поиск и фильтрация:** Поиск по названию и фильтрация по статусу работают «на лету» без перезапуска сцены благодаря связыванию `ObservableList` и `FilteredList`.

## 💻 Инструкция по запуску в IntelliJ IDEA

Проект спроектирован на базе встроенной системы сборки Maven, что исключает необходимость ручного скачивания JavaFX SDK [image_Ehl16c.png].

1. Откройте **IntelliJ IDEA**.
2. Выберите пункт **Open** (или *File -> Open*).
3. Укажите путь к корневой папке проекта `taskmanager` (выберите файл `pom.xml` и нажмите *Open as Project*).
4. Дождитесь автоматической загрузки и индексации зависимостей Maven (строка прогресса в правом нижнем углу среды).
5. Разверните дерево каталогов: `src -> main -> java -> com.example.taskmanager -> HelloApplication.java`.
6. Нажмите на **зеленый треугольник (Run)** рядом с методом `main()` или в верхней панели среды для сборки и запуска GUI.
